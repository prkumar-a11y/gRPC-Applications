DummyServerStream server-streaming

Sends back the received DummyMessage 10 times as a server-side stream.

Request — DummyMessage

FieldTypeNotes
Same fields as DummyUnary above

Stream Response — DummyMessage (×10)

FieldTypeNotes
Identical copy of the request, repeated 10 times

Examples

grpcurl (direct)
grpcurl (Apache 443)
grpcurl -plaintext \
  -d '{"f_string":"ping","f_int32":1}' \
  127.0.0.1:50054 grpcbin.GRPCBin/DummyServerStream
grpcurl -insecure \
  -d '{"f_string":"ping","f_int32":1}' \
  grpc-service-apache-origin.qa.akamai.com:443 grpcbin.GRPCBin/DummyServerStream
The stream sends exactly 10 messages then closes normally.

DummyClientStream client-streaming

Receives 10 DummyMessages from the client and replies with the last one received.

Stream Request — DummyMessage (×10)

FieldTypeNotes
Send 10 DummyMessage frames; server reads all 10 then responds

Response — DummyMessage

FieldTypeNotes
Echo of the last received message

Examples

grpcurl (direct)
grpcurl (Apache 443)
# grpcurl reads newline-delimited JSON from stdin for client-streaming RPCs
printf '{"f_string":"msg1"}\n{"f_string":"msg2"}\n{"f_string":"msg10"}\n' | \
grpcurl -plaintext -d @ \
  127.0.0.1:50054 grpcbin.GRPCBin/DummyClientStream
printf '{"f_string":"msg1"}\n{"f_string":"msg10"}\n' | \
grpcurl -insecure -d @ \
  grpc-service-apache-origin.qa.akamai.com:443 grpcbin.GRPCBin/DummyClientStream
Send as many messages as you want; the server reads until the client closes the stream and returns the last message received.

FieldTypeNotes
Mirror of each received message

Examples

grpcurl (direct)
grpcurl (Apache 443)
printf '{"f_string":"a"}\n{"f_string":"b"}\n{"f_string":"c"}\n' | \
grpcurl -plaintext -d @ \
  127.0.0.1:50054 grpcbin.GRPCBin/DummyBidirectionalStreamStream
printf '{"f_string":"a"}\n{"f_string":"b"}\n' | \
grpcurl -insecure -d @ \
  grpc-service-apache-origin.qa.akamai.com:443 grpcbin.GRPCBin/DummyBidirectionalStreamStream
The server keeps the stream open and echoes each message as it arrives. Close stdin (Ctrl+D) or disconnect the client to end the session.

FieldTypeNotes

Examples

With -proto flag
Response

  -d '{"greeting":"world"}' \
  127.0.0.1:50054 hello.HelloService/SayHello
grpcurl -insecure \
  -d '{"greeting":"world"}' \
  grpc-service-apache-origin.qa.akamai.com:443 hello.HelloService/SayHello

}

grpc.gateway.examples.examplepb.ABitOfEverythingService

ABitOfEverythingService unary server-streaming

A grpc-gateway example service demonstrating a broad set of RPC patterns and field types. Key RPCs: Create, Lookup, Update, Delete, Echo, GetQuery, Timeout, ErrorWithDetails.

This service uses complex message types. Use server reflection (already routed through Apache) or supply the proto directly. Examples below use reflection.

Discover all methods via reflection

grpcurl (direct)
grpcurl (Apache 443)
grpcurl -plaintext 127.0.0.1:50054 \
  grpc.gateway.examples.examplepb.ABitOfEverythingService/describe
# List all methods on the service
grpcurl -insecure grpc-service-apache-origin.qa.akamai.com:443 \
  list grpc.gateway.examples.examplepb.ABitOfEverythingService
